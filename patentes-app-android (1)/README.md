# Registro de patentes (Android)

App Android que registra ingresos de buses: foto de la patente, foto del comprobante del conductor,
lectura automática sin internet (lector de texto de Google ML Kit), validación entre ambas patentes,
nivel de batería o combustible, desperfectos, solicitud de mantención y exportación a Excel con fotos.

## Descargar la app
Entra a la sección **Releases** de este repositorio y descarga `PatentesApp.apk` desde el celular.
Al abrirlo, Android pedirá permiso para instalar apps de este origen: acéptalo.
